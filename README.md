# Ishwor Gupta — Portfolio

Personal portfolio and academic profile website of **Ishwor Gupta**, a 2nd-year Bachelor of Computer Engineering student at **Mega College of Engineering** (affiliated with **Purbanchal University**), **Class Representative (CR)**, and **Vice President of Mega Computing Club**.

## About

This single-page portfolio website presents my academic background, programming and leadership skills, featured student resource platform, campus roles, printable resume modal, and direct contact options[cite: 3].

## Highlights & Features

- **Hero & Profile Card:** Features role typing transitions, quick navigation, social links, and a profile photo frame (`profile.png` with fallback to `profile.jpg`)[cite: 3].
- **About Me & Education:** Covers 2nd-year B.E. Computer Engineering studies at Mega College of Engineering under Purbanchal University[cite: 3].
- **Filterable Skills:** Interactive filtering across **All Skills**, **Technical** (HTML, Python, C Programming, C++, Web Development, Problem Solving), and **Leadership** (Leadership, Project Management, Social Media Management)[cite: 3].
- **Featured Project — PU Computer Engineering Notes:** Highlights the student notes portal ([pucomputerengineeringnotes.blogspot.com](https://pucomputerengineeringnotes.blogspot.com/)) with an expandable portal structure preview[cite: 3].
- **Leadership & Campus Roles:** Details responsibilities as Vice President of Mega Computing Club, Class Representative (CR), and Social Media Handler for student platforms[cite: 3].
- **Printable Resume Modal:** Includes a built-in resume view with print / Save as PDF support[cite: 3].
- **Contact & Collaboration:** One-click email copy buttons, direct phone link, social links, and a contact form (`mailto:` trigger)[cite: 3].

## Built With

- **HTML5** & **Tailwind CSS** (CDN)[cite: 3]
- **JavaScript** (interactive filtering, modal/drawer toggles, clipboard helper, scroll reveal)[cite: 3]
- **Font Awesome** (icons)[cite: 3]
